# 钓鱼游戏 (Fishing Game)

一个使用 Python 和 Pygame 开发的趣味钓鱼游戏，具有完整的图形界面、排行榜系统和鱼类记录功能。

## 游戏特色

### 🎮 游戏功能
- **图形化界面**: 精美的游戏界面，包含水面、天空、钓鱼竿等元素
- **多样鱼类**: 7种不同的鱼类，从常见的小鲫鱼到稀有的巨型鲸鱼
- **排行榜系统**: 记录玩家得分、钓鱼数量和总重量的排行榜
- **鱼类记录**: 详细记录每条鱼的种类、重量、钓鱼者和日期
- **实时统计**: 显示当前钓鱼会话的统计信息

### 🐟 鱼类系统
| 鱼类 | 重量范围(kg) | 稀有度 | 基础分数 |
|------|-------------|--------|----------|
| 小鲫鱼 | 0.1 - 0.5 | 常见 | 10 |

| 鲈鱼 | 1.5 - 6.0 | 普通 | 75 |

## 安装和运行

### 环境要求
- Python 3.7+
- Pygame 2.1.0+

### 安装步骤
1. 克隆或下载游戏文件
2. 安装依赖包:
   ```bash
   pip install -r requirements.txt
   ```
3. 运行游戏:
   ```bash
   python fishing_game.py
   ```

## 游戏操作

### 主菜单
- **输入姓名**: 点击输入框输入你的姓名
- **开始钓鱼**: 输入姓名后点击开始游戏
- **排行榜**: 查看历史最高分记录
- **鱼类记录**: 查看所有钓获的鱼类记录

### 钓鱼界面
- **空格键**: 第一次按下开始抛竿，力量条会变化；第二次按下确定抛竿力量
- **回车键**: 当有鱼上钩时，按回车收线
- **ESC键**: 保存当前成绩并返回主菜单
- **鼠标点击**: 点击"返回菜单"按钮返回主菜单

### 钓鱼技巧
1. **抛竿力量**: 力量越大，钓鱼线投得越远越深，容易钓到更大的鱼
2. **耐心等待**: 鱼上钩是随机的，需要耐心等待
3. **及时收线**: 有鱼上钩时会有提示，要及时按回车收线

## 计分系统

总得分 = 基础分数 + 重量奖励分数
- 基础分数: 根据鱼类稀有度决定
- 重量奖励: 鱼的重量 × 10

## 数据保存

游戏会自动保存两个 JSON 文件:
- `leaderboard.json`: 排行榜数据
- `fish_records.json`: 鱼类记录数据
